# Full Stack TTRPG World Management Tool

A simple tool for a GM to manage a world, containing various parts of the world: Continents, Cities, NPCs and more planned.

## Usage

### Hosting

- Create a PostgreSQL database of the following schema:

```sql
CREATE TABLE continents(id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
name text NOT NULL,
info text)

CREATE TABLE cities(id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
name text NOT NULL,
interest_areas jsonb,
info text,
continent_id bigint REFERENCES continents(id))

CREATE TABLE npcs(id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
name text NOT NULL,
info text,
city_id bigint REFERENCES cities(id))
```

- Add the backend to a hosted service:
  - `gunicorn app:app` to execute.
  - Use the .env.example to create an .env and direct the backend to the PostgreSQL DB.

- `npm run build` the frontend folder.
- Add the dist folder to a hosted service, directing at index.html.

---

### Running

- The Manage page brings a tab for each type of managed content, as well as the options to create them.
- The Continents, NPCS, and Cities pages all contain information and links to each item, with its own page linked from there.
